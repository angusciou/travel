將旅書安裝至手機桌面

🍎 iPhone / iPad (iOS Safari)

  1. 確認您使用的是 Safari 瀏覽器。
  2. 點擊下方工具列的 分享 按鈕。
  3. 在選單中向下捲動並點選 加入主畫面。
  4. 點擊右上角的「新增」，即可在主畫面使用！

🤖 Android (Chrome)

  1. 確認您使用的是 Chrome 瀏覽器。
  2. 點擊右上角選單 。
  3. 點擊 安裝應用程式 或「加到主畫面」。
  4. 依照提示確認安裝即可！
